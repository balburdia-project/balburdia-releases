# Balburdia Desktop Releases

Welcome to the official distribution repository for the **Balburdia** desktop application. Balburdia is a self-hosted, real-time chat and media platform.

> **IMPORTANT NOTICE:** 
> This repository is **strictly used for distributing compiled binaries and installers**. It does **not** contain the Balburdia source code. The core source code is kept in a separate, private repository.

## Downloads & Installation

You can find the latest compiled versions of the Balburdia app for both **Windows** and **Linux** in the GitHub Releases section.

To download and install the app:
1. Navigate to the [Releases](../../releases) tab on the right side of this page.
2. Select the latest release version.
3. Download the appropriate installer for your operating system (e.g., the `.exe` file for Windows or the respective Linux package).
4. Run the installer on your machine.

## Bug Reports & Feedback

Even though the source code is not hosted here, you can use this repository's **Issues** tab to report any bugs, crashes, or feedback specifically related to the desktop application (Windows/Linux clients). 

When opening an issue, please include:
* Your operating system and version.
* The Balburdia app version you are currently using.
* Steps to reproduce the issue.
